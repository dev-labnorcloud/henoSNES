# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.x     | ✅        |

## Reporting a vulnerability

Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/nickheno/henoSNES/security/advisories/new)
or by email to **security@henosnes.org** (placeholder — update when established).

**Do not open a public issue for security vulnerabilities.**

## Response timeline

- **Acknowledgment:** within 48 hours.
- **Assessment:** within 7 days.
- **Fix or mitigation:** within 90 days.

## Responsible disclosure

We follow coordinated disclosure. After a fix is released, we will publish
a security advisory with credit to the reporter (unless they prefer anonymity).
